# Guestbook Project

## Project Name
Guestbook Application

## Project Description
This project is a simple Guestbook application developed as part of the IBM CI/CD Final Project.
The project demonstrates Continuous Integration and Continuous Delivery using GitHub Actions, Tekton, and OpenShift.

## Technologies Used
- Python
- Flask
- GitHub
- GitHub Actions
- Tekton
- OpenShift
- Docker
- Buildah

## CI/CD Features
- Source code management using GitHub
- Linting using Flake8
- Unit testing using Nose
- Container image building
- OpenShift deployment

## Testing
The GitHub Actions workflow runs Flake8 for linting and Nose for unit testing.

## Deployment
The application is designed to be deployed to OpenShift using a Tekton CI/CD pipeline.

## Project Status
The project contains the required CI/CD configuration and testing files for the final project.
